# 🍬 Museum of Candy

A responsive, scrollable website concept for a fictional "Museum of Candy" — designed to showcase different candy-themed exhibits through a clean, image-driven layout.

## 🌐 Overview

Museum of Candy is a front-end web project that reimagines a museum experience around the world of confectionery. Visitors can scroll through different sections, each highlighting a unique "exhibit" with imagery and descriptions, all tied together with a smooth, scroll-aware navigation bar.

## ✨ Features

- Fully responsive layout built with Bootstrap
- Custom-styled sections with a cohesive color palette
- JavaScript-powered scrollable/sticky navbar for smooth navigation
- Multiple themed "exhibit" sections with imagery and copy
- Clean, minimal typography and layout

## 🛠️ Built With

- **HTML5** – page structure
- **CSS3** – custom styling
- **Bootstrap** – responsive grid and components
- **JavaScript** – navbar scroll behavior
- ## 📚 What I Learned

This project was a hands-on way to practice structuring a multi-section site with Bootstrap's grid system and to get comfortable using JavaScript for simple DOM interactions like a scroll-based navbar.
